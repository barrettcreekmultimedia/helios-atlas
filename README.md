# HELIOS ATLAS 🌞

**A cinematic interactive 3D tour of our solar system**, built with the real [PlayCanvas Engine](https://github.com/playcanvas/engine) (not Three.js) and designed to be hosted directly on GitHub Pages.

## ✨ Features

- Sun, all **eight planets**, and all **five IAU-recognized dwarf planets** (Ceres, Pluto, Haumea, Makemake, Eris)
- **Eight selected major moons**, including Earth's Moon, Europa, Io, Ganymede, Titan, and Triton
- Volumetric **Asteroid Belt**, disk-like **Kuiper Belt**, and a massive spherical **Oort Cloud** visualization
- Smooth cinematic fly-to navigation, mouse-orbit / scroll zoom / touch pinch, animated planet orbits and axial spins
- Camera presets, searchable object list, visible orbit paths, configurable layers, speed and pause controls
- Quick-reference scientific facts and measurements in the detail panel
- Generated original texture assets, no remote texture or model dependencies
- Mobile-friendly interface, lightweight static deployment

### Important scientific note

This is an **exploratory art/education piece, not a physics simulator**. Planet sizes and orbital distances are dramatically compressed, and orbital inclinations, timing, and positions are illustrative, not calculated from orbital elements or a date-based ephemeris. The Oort Cloud has **not** been directly observed; its depiction is conceptual. The planetary textures are procedurally generated artwork, not geographically accurate maps. Values in the information panel are approximate reference figures.

## 🚀 Deploy to GitHub Pages (no build required)

1. Unzip this package and create a new GitHub repository, e.g. `helios-atlas`.
2. Upload **the contents of the `helios-atlas` folder to the root** of the repo: `index.html`, `style.css`, `src/`, `assets/`, and `.nojekyll`.
3. Open GitHub → repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**. Set **Branch: `main`**, Folder: **`/(root)`**; save.
5. When Pages publishes, your site will be at `https://YOUR-USERNAME.github.io/helios-atlas/` (or at your custom domain).

**Important:** This project uses the actual PlayCanvas Engine loaded from a version-pinned jsDelivr CDN. Your visitors need internet to load that JavaScript. All image textures are in the repo and need no third-party host. The project uses **relative paths** for assets, so project-repository URLs work on GitHub Pages without editing anything.

## 💻 Run locally

You need a modern browser with WebGL 2, and an internet connection for PlayCanvas.

**Windows:** double-click `run-local.bat` (Python must be installed). It opens `http://localhost:8000` and starts the local server. Keep the terminal window open while using the atlas.

**macOS/Linux:** in this folder run:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

**No Python?** With Node.js installed, run `npx serve .` and open the address shown. *Don't* open `index.html` directly with `file://` — browsers restrict ES modules and file textures.

## 🎮 Controls

| Control | Action |
| --- | --- |
| Click object, or select from left sidebar | Smoothly fly to its orbit |
| Left drag / one-finger drag | Orbit your camera |
| Scroll wheel / two-finger pinch | Zoom in and out |
| `/` | Focus search |
| `←` / `→` | Previous / next object |
| Space | Pause / play the orbits |
| `R` | Return to Saturn |
| Bottom navigation tabs | Inner / full / Kuiper / Oort views |
| Layers switches | Display or hide small bodies and orbital paths |

## 🛠 Technical notes

- PlayCanvas Engine **v2.23.3**, imported via ES modules. This is a **standalone PlayCanvas Engine project**, which is ideal for GitHub Pages; it is *not* a PlayCanvas Editor scene export. It can be migrated into the PlayCanvas Editor as a follow-on project.
- Renders with WebGL 2; the UI is ordinary HTML and CSS.
- Asteroids, Kuiper bodies, and Oort cloud particles are rendered as GPU point-cloud meshes, not thousands of individual game objects.
- Original planet textures can be regenerated by running `python generate_textures.py` after installing NumPy and Pillow. The JPGs are already supplied; regeneration is optional.
- To update the PlayCanvas version, change the version-pinned CDN URL in `index.html` and test the scene before publishing.
